## 📥 Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top-right corner
3. Click "Load unpacked" and select the extension directory
4. The extension should now appear in your toolbar

## 🔑 API Setup

1. Create a Google Cloud Project:
   - Visit [Google Cloud Console](https://console.cloud.google.com)
   - Create a new project or select an existing one
   - Enable YouTube Data API v3

2. Generate API Credentials:
   ```
   - Go to APIs & Services > Credentials
   - Click "Create Credentials" > "API Key"
   - Copy your API key
   ```

3. Configure the Extension:
   - Click the extension icon
   - Go to Settings > API Management
   - Paste your API key in the designated field
   - Click "Verify" to test the connection

## 🔧 Troubleshooting

If you encounter any issues:

1. Check the browser console for error messages
2. Ensure your YouTube API key is valid and has the necessary permissions
3. Try reloading the extension from the extensions page
4. Clear your browser cache and restart Chrome
